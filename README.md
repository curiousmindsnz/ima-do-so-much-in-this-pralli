# ima-do-so-much-in-this-pralli

## 🎮 Number Guessing Game

A fun and interactive number guessing game built with HTML, CSS, and JavaScript!

### How to Play

1. Open `index.html` in your web browser
2. The game will generate a random number between 1 and 100
3. Try to guess the number by entering your guess in the input field
4. The game will tell you if your guess is too high or too low
5. You'll also get temperature hints (cold, warm, hot, very hot) based on how close you are
6. Try to guess the number in as few attempts as possible!
7. Your best score is saved locally in your browser

### Features

- 🎯 Interactive guessing with real-time feedback
- 🌡️ Temperature-based hints (cold/warm/hot)
- 📊 Attempt counter and best score tracking
- 📜 Guess history with color coding
- 🏆 Local best score persistence
- 🎨 Beautiful gradient UI design
- 📱 Responsive design for mobile devices

### Technologies Used

- HTML5
- CSS3 (with gradients and animations)
- Vanilla JavaScript
- LocalStorage for score persistence

Enjoy the game! 🎉
